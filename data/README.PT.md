# Referência de Dados

O objetivo deste repositório é centralizar o máximo possível as informações e
configurações que utilizarei no GitHub. Como certos dados não podem ser associados
diretamente a arquivos padrão da comunidade ou a configurações em YAML, eles são
armazenados nesta pasta.

Abaixo, é possível consultar todos os detalhes relevantes sobre o que está armazenado
aqui. Observe que o uso pode estar restrito à minha própria configuração e talvez
não seja relevante para outros tópicos.

## Labels

O GitHub permite adicionar labels tanto a Issues quanto a Pull Requests, mas as
labels disponibilizadas na criação do repositório estão longe de atender aos meus
padrões. Seguindo [estas][sane] dicas para torná-los mais "sensatos", criei um
conjunto de labels personalizadas para estruturar e facilitar meus fluxos de
trabalho, especialmente quando estes passaram a ser automatizados.

Para as referências de cores, decidi consultar diretamente o Primer UI do próprio
GitHub, que pode ser conferido acessando [esta][primer] página. Além disso, para
visualizar as labels formatadas que estou utilizando atualmente, basta clicar no
arquivo desejado abaixo:
