# Referencia de Datos

El objetivo de este repositorio es centralizar la mayor cantidad posible de información
y configuraciones que utilizaré en GitHub. Dado que ciertos datos no pueden asociarse
directamente a archivos estándar de la comunidad ni a configuraciones YAML, se
almacenan en esta carpeta.

A continuación, se pueden consultar todos los detalles relevantes sobre lo que se
almacena aquí. Por favor, tenga en cuenta que su uso puede estar muy limitado a
mi propia configuración y podría no ser relevante para otros temas.

## Labels

GitHub permite asignar labels tanto a los Issues como a los Pull Requests, sin
embargo, las labels que se incluyen por defecto al crear un repositorio no cumplen,
ni de lejos, con mis estándares. Siguiendo [estos][sane] consejos para hacerlas
más «sensatas», creé un conjunto de labels específicas para optimizar y facilitar
mis flujos de trabajo, especialmente de cara a su automatización.

Para consultar los colores, decidí revisar directamente la referencia de Primer
UI, el sistema de diseño de GitHub, a la que se puede acceder en [esta][primer]
página. Además, para visualizar las labels con el formato que estoy utilizando
actualmente, basta con hacer clic en el archivo correspondiente que aparece abajo:
