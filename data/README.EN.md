# Data Reference

The objective for this repository is to store the most centralized amount of information
and configuration I shall use in GitHub. Following that, certain data can't be directly
associated in community standard files or YAML configuration, so it's stored in
this folder.

Below all relevant details regarding what is stored here can be read and accessed.
Please notice that its usage may be very restricted to my own configuration and
it may not be relevant for other topics.

## Labels

GitHub allows both for Issues and Pull Requests the possibility to be labelled,
yet the labels provided on repository creation are by far not useful to my standards.
Following [these][sane] tips on how to let them be more "sane", I created a bunch
of unique labels to fill and ease my workflows, specially when they became automatized.

For the reference on colors, I decided to check directly on the reference for GitHub's
own Primer UI, which can be checked accessing [this][primer] page. Also, to visualize
the labels I'm currently using formatted, you can just click on your desired file
below:
